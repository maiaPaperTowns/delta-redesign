Design notes

Blue = fewer slips · Teal = complexity shifted · Orange = harmful nudge removed · Purple = nudge made ethical

  1. 1Nav cut from 11 top-level links + 7 utility links to 5 task-based items. Gift cards and Amex links move to the footer and SkyMiles area, so the header only carries what people come to do.
  2. 2Removed the red "3" notification badge shown to signed-out visitors (fake urgency) and the red Log in button competing with Find Flights. One quiet Sign in, one text link to join.
  3. 3Trip type is a visible segmented control, not a hidden dropdown. From/To are labeled fields that show code + city + airport, preventing wrong-airport slips (IND vs IDA).
  4. 4Depart and Return are separate labeled fields with the weekday shown. Return can't be set before Depart; picking One way removes Return instead of leaving a stale date.
  5. 5"Include Basic" (unchecked by default) hid the cheapest fare and steered people up. Now every fare type shows in results, with Basic's restrictions written out there. The fare decision moves to the results page, where it has context.
  6. 6Refundable-only is still offered, but a short line says what it means and that it usually costs more, instead of a tiny "?" tooltip.
  7. 7A live summary sentence reads the search back before submit, so people can catch a wrong date, airport or traveler count before they reach results.
  8. 8Recent searches and "resume" chips: the system remembers the trip, not the traveler. Clear history is right beside them.
  9. 9The most common tasks (check in, status, change/cancel, bag fees) sit above any marketing. Bag fees were a small utility link; now they're a first-class shortcut (fee transparency).
  10. 10The card offer stays but is honest: labeled as an ad from a partner, moved below tasks, no strikethrough 80K anchor or "Highest offer this year" urgency. Annual fee, minimum spend, deadline and credit check are shown up front, plus a Hide card offers option.
  11. 11"Unlock 15% off" implied everyone qualifies. The headline now names who's eligible and the exclusions sit in the body, not behind "Terms apply."
  12. 12Vague "Details" links become descriptive ones ("Browse hotels & cars"), and every off-site link gets the same ↗ marker. Clicks become predictable and screen-reader friendly.
